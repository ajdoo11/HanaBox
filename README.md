# HanaBlox 🌍

Eine Klötzchen-Spielwelt für Kinder – ohne Waffen, mit Freunden online spielen.
Hana-Stadt, Schneeland, Tropeninsel und Zauberwald: Häuser und Läden zum Betreten, Jobs, Haustiere, Fahrzeuge und Boote, Strand und Meer, Bauen, Bot-Freunde und Sprachchat.

## Sofort spielen
**https://ajdoo11.github.io/HanaBox/** – läuft direkt im Browser (auch auf dem Tablet), mit Bot-Freunden. Spielstände werden auf dem Gerät gespeichert.

## Mit Freunden und Sprachchat
Dafür braucht es den Online-Server: mit `render.yaml` auf [Render](https://render.com) als Blueprint starten und die Adresse in `public/js/config.js` bei `SERVER_URL` eintragen (z.B. `wss://hanablox.onrender.com/ws`). Danach verbindet sich auch der GitHub-Link mit dem Server.

## Auf dem eigenen PC starten
```bash
npm install
npm start
```
Dann `http://localhost:3000` öffnen.

Mehr in der [Anleitung](ANLEITUNG.md).
